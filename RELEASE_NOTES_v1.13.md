# Brain Arena v1.13.1 – Red Sidebar Toggle

Update ini mempertahankan redesign merah v1.13 dan memperbaiki perilaku sidebar agar sesuai referensi.

- Tombol **Ubah Sidebar** ditambahkan di topbar desktop.
- Klik tombol mengubah sidebar **Full ↔ Compact/Rail**.
- Shortcut: `Ctrl + Shift + S` (atau `Cmd + Shift + S` di macOS).
- Status sidebar disimpan di `localStorage`, jadi pilihan tetap saat halaman dibuka lagi.
- Pada mobile, tombol toggle desktop disembunyikan dan menu tetap memakai drawer/hamburger.
- Tema merah, game, progression, feedback, dan fitur v1.12/v1.13 lainnya tetap dipertahankan.
